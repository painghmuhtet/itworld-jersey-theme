# iT World Jersey

This repository now contains a complete WordPress theme scaffold named "iT World Jersey".

What's included:

- style.css (theme header)
- functions.php (setup, enqueue, widgets, WooCommerce wrappers)
- index.php, single.php, page.php, archive.php, 404.php
- header.php, footer.php, sidebar.php, searchform.php
- assets/css/style-main.css and assets/js/navigation.js

How to test/install locally:

1. Clone this repository.
2. In your WordPress installation, copy the `itworld-jersey-theme` folder into `wp-content/themes/` or install via Git.
3. Activate the theme from the WordPress admin > Appearance > Themes.
4. Add menus (Appearance > Menus), set a static front page if desired, and add widgets to the Sidebar.
5. If using WooCommerce, the theme declares support; check product pages and layouts.
